Ejercicio--1-semaforo-

Descripción

Este circuito simula el funcionamiento de un semáforo utilizando un Arduino Uno y tres LEDs: rojo, amarillo y verde.
Cada LED se enciende durante un tiempo determinado para representar las diferentes señales de un semáforo.
El LED rojo permanece encendido durante 5 segundos, el amarillo durante 2 segundos y el verde durante 5 segundos.
Al finalizar la secuencia, el ciclo vuelve a comenzar automáticamente.

Componentes utilizados
Arduino Uno
1 LED rojo
1 LED amarillo
1 LED verde
3 resistencias de 220 Ω
Protoboard
Cables 

Instrucciones de uso:
Para usar el circuito en Tinkercad, abre el enlace del proyecto y presiona “Iniciar simulación” para ver cómo funciona el semáforo.
Si quieres hacerlo físicamente, conecta los tres LEDs al Arduino según los pines indicados y luego enciende el Arduino para comprobar que las luces cambien automáticamente.
